# period-tracker
生理の記録と、周期の予測・確認に絞ったPWA

## 現在の画面

初期設定、月間カレンダー、生理の開始・終了と日付修正、年月一覧からの移動に対応しています。記録はブラウザの localStorage に保存します。実際の記録やバックアップはこの公開リポジトリへ入れません。

生理の記録・開始日の予測は円で色を付け、排卵とPMSの目安は円の枠線で示します。タップした日を実線で囲みます。左右スワイプで前後の月へ移動できます。終了日未入力の場合は開始日から5日間を1日ずつ薄く仮表示し、終了日入力後は同色になります。年月一覧は記録のある月に枠線、今月に塗りを付けます。

## 合意した予測方法

- ◎本命：直近最大3周期の中央値を四捨五入。
- ○対抗：最新の開始日から6か月さかのぼった日以降に始まった、完了した周期の平均を四捨五入。
- 周期日数の入力は補助です。入力しない場合は「不明」として保存し、開始日が1回だけなら入力した日数を、入力がなければ仮の28日を予測の参考にします。この仮値は記録へ保存しません。
- 2回目の開始日以降は本人の記録だけで計算し、仮の28日や入力した周期日数を平均に混ぜません。半年以内の周期がない場合の対抗には本人の直近周期の中央値を使います。
- 開始日の記録がなければ予測しません。
- 最新の開始日から次の開始日を予測します。予定日を過ぎても、記録を追加せずに予測を次の周期へ繰り返し進めることはしません。
- 排卵予定日：本命の14日前。PMSが出やすい時期：本命の10日前〜3日前。目のアイコンから表示を切り替えられます。
- 同日の本命・対抗は同じ円に両方の意味を持たせます。記録と予測が重なる場合は記録を優先します。

これらはユーザーと合意した表示上の目安です。排卵の確定やPMSの診断には使いません。参考：[NHSの月経周期の説明](https://www.nhs.uk/conditions/periods/fertility-in-the-menstrual-cycle/)、[RCOGのPMSの説明](https://www.rcog.org.uk/for-the-public/browse-our-patient-information/managing-premenstrual-syndrome-pms/)。

## 記録が空いた区間

- 隣り合う開始日から求めた区間が、本人の最短周期の2倍以上なら確認候補にします。比較できる区間が2つ以上必要です。記録不明の区間は比較から外します。
- 最初の候補は小さなポップアップで案内します。自動表示は画面を開いてから1回だけ。閉じた後はカレンダー下から確認できます。
- 「記録し忘れた」では区間内に開始日を追加できます。日付が曖昧な場合も、分かる範囲の日付で記録します。
- 「生理は来たが、日付を忘れた」は `intervalReviews` に `kind: unknown` として保存。日数不明の区間として予測から除外し、前後をつないだ周期は作りません。
- 「実際に生理が来なかった」は `kind: long` として保存。実際の日数を履歴に残し、通常の4分の1の重みで計算します。
- 本命は予測に使える直近最大3周期の加重中央値、対抗は半年以内の加重平均を使います。通常の周期は重み1です。重みが等しい場合はこれまでの中央値・平均と同じ結果になります。
- 直近3区間で「実際に長かった」と確認された周期が2つ以上あれば、その最近の長い周期は重み1に戻します。通常の周期が続けば以前の長い周期の重みは再び4分の1になります。この重みと回数は初期の実装値です。
- 未確認の区間は通常の重みで残します。「周期を確認・編集」の履歴から判断を変更できます。
- 判断は前後の開始日の組に結び付けます。開始日を修正したり間に記録を追加したりすると、消えた区間の判断は保存時に取り除きます。
- 周期日数は任意入力で、空欄のまま保存できます。開始日が2件以上ある場合は入力した周期日数を予測に混ぜず、記録した周期から計算します。
- 予測に使える区間が残らない場合は予測を出しません。複数の開始日があるのに初期値の28日へ戻すことはしません。
